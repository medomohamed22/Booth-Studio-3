# Changelog

## 3.0.1

- Fixed empty model/material/HDRI preview cells in the native image picker.
- Scoped picker entries to the same page as the thumbnail loader.
- Kept selection valid when changing pages or gallery column count.
- Added safe handling for empty catalogs and final partial pages.
- Displayed a loading icon while preview images are being fetched.

## 3.0.0

- Added the large asset browser, tabbed workspace and advanced controls.
- Added combined library search, organization, preview metadata and a download queue.
- Added bounded preview caching and next-page prefetch.
- Added quick grain direction, live material mapping and map-resolution replacement.
- Added lighting profiles, A/B snapshots, pinned lights, Solo, light linking and the visual light map.

## 2.1.0

- Added image cards and paginated previews for library search results.

## 2.0.0

- Added Poly Haven and ambientCG integration, PBR mapping controls, HDRI tools and six lighting styles.
